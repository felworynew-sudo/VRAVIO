# Десктопное приложение

Тот же редактор, что и в вебе, в своём окне. Оболочка вокруг него —
пятнадцать строк Rust в `apps/desktop/src-tauri`, которые не знают о
документах ничего.

## Откуда брать готовые сборки

Вкладка **Actions** в репозитории → workflow «Десктопные сборки» → кнопка
**Run workflow**. Через несколько минут внизу страницы прогона появятся два
архива: `VRAVIO-Windows` (`.msi` и установщик `.exe`) и `VRAVIO-macOS`
(`.dmg`, одна сборка и для Apple Silicon, и для Intel).

## Как открыть на macOS

Приложение **не подписано** сертификатом Apple — подпись стоит $99 в год и
нужна только для раздачи чужим людям. Поэтому при первом запуске macOS
скажет что-то вроде «не удаётся проверить на наличие вредоносного ПО».

Открыть можно двумя способами:

1. **Правый клик по VRAVIO в папке «Программы» → «Открыть»**, затем «Открыть»
   в появившемся окне. Один раз; дальше запускается обычным двойным щелчком.
2. Если первый способ не сработал (в свежих версиях macOS бывает жёстче) —
   в Терминале:
   ```
   xattr -dr com.apple.quarantine /Applications/VRAVIO.app
   ```
   Эта команда снимает метку «скачано из интернета», больше ничего.

## Как открыть на Windows

SmartScreen покажет синее окно «Windows защитила ваш компьютер». **Подробнее**
→ **Выполнить в любом случае**. Причина та же — нет подписи; сертификат для
Windows стоит от $200 в год, а с дешёвым вариантом окно всё равно остаётся,
пока не накопится репутация по числу скачиваний.

## Собрать самому

Нужны Rust и, на Windows, MSVC Build Tools (см. раздел 8 в `CLAUDE.md` —
там записано, где они стоят на машине владельца).

```
cd apps/desktop
pnpm tauri build
```

Собранное лежит в `apps/desktop/src-tauri/target/release/bundle/`.
Первая сборка — около десяти минут, дальше около минуты: пересобирается
только оболочка, а зависимости лежат в `target/`.

Для повседневной работы над интерфейсом десктоп не нужен вовсе — `pnpm tauri
dev` показывает тот же дев-сервер Vite с горячей заменой модулей, а Rust при
правке `.tsx` не пересобирается.
